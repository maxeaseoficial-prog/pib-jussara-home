# First Light Home

OBJETIVO

Desenvolver somente a PÁGINA INICIAL (HOME) pública da Primeira Igreja Batista de Jussara - GO (PIB Jussara), do cabeçalho ao rodapé.

Esta é a FASE 1.

Não desenvolver ainda:

- login;

- cadastro;

- área de membros;

- autenticação;

- dashboard;

- painel administrativo;

- banco de dados;

- Supabase;

- calendário completo;

- páginas internas;

- backend.

O objetivo desta fase é entregar uma Home institucional extremamente bem resolvida, moderna, profissional, acolhedora e responsiva.

Não antecipar funcionalidades futuras.

==================================================

1. CONCEITO VISUAL

==================================================

Criar uma identidade visual contemporânea para uma igreja Batista brasileira.

O site deve transmitir:

- fé;

- acolhimento;

- comunhão;

- confiança;

- seriedade;

- proximidade;

- modernidade;

- pertencimento.

A linguagem visual deve combinar:

1. grandes áreas claras e sofisticadas;

2. verde institucional profundo;

3. verde vivo da identidade da igreja;

4. fotografias reais como protagonistas;

5. tipografia grande e forte;

6. bastante espaço negativo;

7. blocos editoriais assimétricos;

8. seções escuras pontuais para criar contraste;

9. bordas arredondadas moderadas;

10. ícones lineares minimalistas.

O site NÃO pode parecer:

- template pronto;

- landing page SaaS;

- dashboard;

- site feito por IA;

- site religioso antigo;

- interface infantil;

- página construída apenas com cards;

- página cheia de gradientes e efeitos.

Queremos aparência de site institucional desenvolvido sob medida por uma agência de design.

16. MOTION DESIGN

==================================================

Motion deve transmitir refinamento.

Não transformar a página em demonstração de animações.

Se Motion/Framer Motion já existir no projeto, utilizar.

Caso contrário, não adicionar uma biblioteca pesada apenas para animações simples se CSS + IntersectionObserver forem suficientes.

ENTRADA DAS SEÇÕES

Ao entrar no viewport:

opacity: 0 → 1

translateY: 20px → 0

Duração aproximada:

500–700ms.

Easing suave.

HEADLINES

Revelação progressiva discreta.

Não animar cada letra.

CARDS

Stagger:

aproximadamente 60–100ms.

IMAGENS

Reveal suave.

Opcional:

scale 1.03 → 1.

BOTÕES

Hover:

- background transition;

- translateY máximo 1–2px;

- seta desloca aproximadamente 3px.

CARDS

Hover desktop:

translateY máximo -4px.

Imagem:

scale máximo 1.03.

HEADER

Animar mudança de estado durante scroll.

PARALLAX

Se utilizado, somente em elementos decorativos grandes e com deslocamento extremamente pequeno.

Nunca comprometer performance.

Implementar:

prefers-reduced-motion.
